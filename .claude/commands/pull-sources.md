# Pull Sources

Fetch fresh material from all configured sources into raw/, then prompt Adrian to triage and run /ingest.

---

## Source 1 · Claude Code Sessions (always on)

Read JSONL session files from `~/.claude/projects/` (all subdirectories).

**Pull:** All `.jsonl` files whose filename timestamp falls within the last 7 days.
**Volume cap:** At most 20 files per run, taking the 20 most recent by file modification time.
**Include filter:** Any session file modified within the last 7 days.
**Exclude filter:** None.
**Dedupe:** Skip any file whose `session_id` matches an existing file in `raw/claude-sessions/`. Derive `session_id` from the JSONL filename (strip the `.jsonl` extension).
**Write to:** `raw/claude-sessions/`
**Naming:** `YYYY-MM-DD-<auto-slug>.md` where the date is the session start date and the slug is a short (3–5 word) summary of the session's dominant topic, generated by reading the first few exchanges in the JSONL.

For each file written, prepend above the YAML frontmatter:

```
> claude-sessions: Adrian, <session topic>. <One-sentence summary of what was discussed or built.>
```

Then write the YAML frontmatter:

```yaml
---
source: claude-code
captured: YYYY-MM-DD
session_id: <jsonl filename without extension>
---
```

Then write a Markdown summary of the session: key decisions made, files changed, commands run, and any open questions left at the end.

**If `~/.claude/projects/` is missing or empty:** Print `[pull-sources] Source 1 skipped: no Claude Code session files found.` and continue.

## Source 2 · Gmail

Pull email via the Gmail MCP connector.

**Pull:** Last 7 days. Both received (where Adrian is in To or Cc) and sent (where Adrian is the From address).
**Volume cap:** At most 10 emails per run, taking the 10 most recent by received/sent date.
**Include filter:** Emails where Adrian appears in To, Cc, or From.
**Exclude filter:** Skip any email whose subject matches calendar notification patterns (subjects containing "Invitation:", "Accepted:", "Declined:", "Updated:", "Cancelled:", or sent from addresses containing `calendar-notification`, `calendar@`, or `noreply`).
**Dedupe:** Skip if a file with the same name already exists in `raw/gmail/`. Derive subject slug from the email subject in kebab-case, lowercased, spaces and punctuation replaced with hyphens, truncated to 60 characters. Append `-sent` to the slug for outgoing emails (where Adrian is the From address) to avoid collisions with received emails on the same subject.
**Write to:** `raw/gmail/`
**Naming:** `YYYY-MM-DD-<subject-slug>.md` for received; `YYYY-MM-DD-<subject-slug>-sent.md` for sent.

For each file written, prepend above the YAML frontmatter:

```
> gmail: <From name or address>, <subject>. <One-sentence summary of what the email is about.>
```

Then write the YAML frontmatter:

```yaml
---
source: gmail
captured: YYYY-MM-DD
---
```

Then write the email body in plain Markdown (strip HTML, preserve links as Markdown links).

**If the Gmail connector is not configured or returns an error:** Print `[pull-sources] Source 2 skipped: Gmail connector unavailable.` and continue.
