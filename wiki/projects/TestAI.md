# TestAI

TestAI is Adrian's personal machine learning experimentation sandbox. It contains standalone implementations of major deep learning and reinforcement learning architectures used for learning and testing.

## Implementations

### Deep Learning

- `CNN.py` — [[Convolutional Neural Network]].
- `RNN.py` — [[Recurrent Neural Network]].
- `Transformer.py` — [[Transformer]] architecture.
- `VAE.py` — [[Variational Autoencoder]].
- `Autoencoder.py` — standard autoencoder.
- `three_layer_neural_network.py` — basic feedforward network.
- `Untitled.ipynb` — Jupyter notebook (contents not yet read).

### Reinforcement Learning

- `Frozen_Lake_w_Q_learning_RL.py` — [[Q-Learning]] on the Frozen Lake environment.
- `dqn_acrobot.py` — Deep Q-Network on the Acrobot environment.
- `Pendulum_SAC_soft_action_critic_RL.py` — [[Soft Actor-Critic]] on the Pendulum environment.

### Utilities

- `test_cuda.py`, `test_GPU.py` — GPU and CUDA availability checks.

## Technologies

- Python, PyTorch or TensorFlow.
- Jupyter.
- CUDA (GPU acceleration).

## Status

Personal learning repository. Not a product. Actively used for experimenting with new architectures.
