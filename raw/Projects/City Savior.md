# City Savior

## Overview
An assistive technology project combining a smart wheelchair and a heart rate monitor. Intended for use in a smart city context. Includes a related "smart walker" component (see `smart walker.pdf` in project folder).

## Key Files
- `main.py` — main application entry point.
- `Weelchair.py` / `wheelchair.py` — wheelchair control logic.
- `heartrate_monitor.py`, `hrcalc.py`, `max30102.py` — heart rate monitoring using the MAX30102 sensor.
- `smart walker.pdf` — supporting documentation for the smart walker component.

## Technologies
- Python.
- MAX30102 pulse oximeter / heart rate sensor.
