# TCM Chatbot

## Overview
A Traditional Chinese Medicine chatbot built as a full-stack web application using Next.js. Deployed on Vercel. Includes authentication, Docker support, and end-to-end tests with Playwright.

## Key Files
- `next.config.ts`, `package.json` — Next.js configuration and dependencies.
- `auth.config.ts`, `auth.ts` — authentication setup.
- `docker-compose.yml` — containerised deployment.
- `playwright.config.ts` — end-to-end test configuration.
- `vercel.json`, `vercel-template.json` — Vercel deployment configuration.
- `CLAUDE.md` — project-level instructions for Claude Code.

## Technologies
- TypeScript, Next.js, React.
- Docker.
- Playwright (E2E testing).
- Vercel (deployment).

## Status
Active or completed. CI configured (GitHub Actions: lint, Playwright). Deployment-ready.
